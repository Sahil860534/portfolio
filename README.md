## 🌟 Highlights & Features

- **Fresher-Optimized Profile:** Tailored specifically for entry-level Software Developer, .NET Developer, Python Developer, and AI Engineer roles.
- **Electric Teal & Cyan Aesthetic:** Modern cyber-clean theme with sleek glassmorphism cards, glowing borders, and smooth dark/light mode toggle.
- **Real Project Case Studies:**
  - **InvoiceOS (P2 Invoice Management):** Full-stack ASP.NET Core Web API + SQL Server + React for automated enterprise billing, GST calculation, and PDF invoicing.
  - **AI Job Search Copilot:** Autonomous multi-agent job application orchestrator built with LangGraph, Python, and Ollama/Gemini.
  - **BEAST (Automated Code Generator):** Multi-agent LLM system synthesizing full-stack apps and test suites from prompt specs.
- **Authentic Credentials:** B.E. in Information Technology (2025) from Shri Kashibai Navale College of Engineering, Pune + Revature .NET Full Stack Training + IBM SkillsBuild Trainee.
- **Interactive Resume Modal:** Clean, printable ATS-friendly resume view with 1-click print and PDF save.
- **Automated CI/CD:** GitHub Actions and `gh-pages` workflow automatically builds and deploys updates on every push to `main`.

## 🚀 Local Development

```bash
# 1. Clone repository
git clone https://github.com/Sahil860534/portfolio.git
cd portfolio

# 2. Install dependencies
npm install

# 3. Start local dev server
npm run dev
```

Visit [http://localhost:5173](http://localhost:5173) in your browser.

---

## 📦 Build & Deploy

```bash
# Build production bundle
npm run build

# Deploy to GitHub Pages
npm run deploy
```
